Zishu Terminal v5.6.5-beta.1

Zishu Terminal is a lightweight, Android-based developer environment. No root required. No native binaries. Just install and use the terminal.

This is v5.6.5-beta.1 — a beta release that adds one new feature and fixes several real bugs. Here's what changed.

---

🆕 New Feature — zgit clone

You can now clone public GitHub repositories directly inside the terminal:

```bash
zgit clone https://github.com/octocat/Hello-World
```

How it works:

· Downloads from GitHub's official codeload ZIP endpoint
· HTTPS with certificate verification
· Branch auto-detect — tries main, falls back to master
· Safe ZIP extraction — path traversal protection, size limits
· Extracts into a local folder and flattens the top-level directory

Example:

```bash
zgit clone https://github.com/github/gitignore
ls gitignore
# Actionscript.gitignore, Android.gitignore, Python.gitignore, ...
```

Is this git? No. It's a Java-based subset of git clone — for public repos and latest snapshots only. There is no git pull, git push, or commit history. We're honest about that.

---

🐛 Bug Fixes in v5.6.5-beta.1

1. Binary Output Rendering Fixed

Before: Running cat a.txt.zenc (an encrypted binary file) showed nothing. The output would suddenly appear only after the next command.

Why: The shell reader used BufferedReader.readLine(), which waits for a newline. Binary data has no newlines, so output got stuck in the buffer.

Now: Byte-level reading with a 100ms idle flush and an 8KB threshold — binary output renders immediately.

```bash
cat a.txt.zenc
# ZENCdZ...a.txt... (immediately)
```

2. zrun Is Now Shebang-Aware

Before: zrun script.sh always ran scripts through /system/bin/sh, even when the script started with #!/bin/bash. Bash-specific scripts failed with:

```
syntax error: unexpected operator/operand '=~'
```

Now: zrun reads the first line, detects the shebang, and finds the correct interpreter:

Shebang Interpreter Behavior
#!/bin/bash searches for bash Not found → clear error
#!/usr/bin/env python3 searches for python3 Not found → clear error
#!/system/bin/sh sh Runs
No shebang sh (default) Runs

No silent fallback. If bash isn't available, you get a clear error:

```bash
zrun test_bash.sh
# zrun: interpreter not available: bash
#       (script shebang requires 'bash')
```

3. zrun Path Resolution Fixed

Before: zrun /absolute/path/script.sh → "Not found"

Now: All of these work:

```bash
zrun test1.sh                          # relative
zrun ./test1.sh                        # relative with ./
zrun /data/.../test1.sh                # absolute
zrun ~/scripts/test.sh                 # home
zrun $HOME/scripts/test.sh             # env var
```

4. zrun Verbose Mode

```bash
zrun -v test1.sh
# Interpreter: /system/bin/sh
# Script:      /data/.../test1.sh
# Shebang:     #!sh
```

Can also be enabled with the ZRUN_VERBOSE=1 environment variable.

5. zgit Documentation in zhelp

zhelp now includes zgit examples.

⚠️ Beta Notice — Honest Disclosure

This is a beta build. Some things are incomplete:

zpkg Remote Support — Disabled

Remote package downloads are disabled in this build. They are planned for a future release.

What works now:

· Local .zpkg directory installation
· Repository management (config only)
· Package database tracking

What doesn't work yet:

· Downloading from remote repositories
· Remote search/info

This feature is planned for v6.0.0 with shell-script packages.

Native Binaries — Not Supported

· Python, Git, Node.js, GCC, Clang — these are native binaries
· Android 10+ W^X restriction prevents executing native binaries from app-private directories
· Termux solves this by bundling binaries in the APK's lib/ folder
· That requires NDK + Gradle, which isn't available in our current environment
· We don't fake features. These things aren't here, and we say so clearly

zgit Limitations

· Public repositories only
· Latest snapshot only — no git history
· No git pull, git push, or git commit
· Equivalent to git clone only

This Is Not Termux

We don't claim this is a Termux replacement. Termux provides a real Linux toolchain (Python, Git, Node, compilers). Zishu Terminal provides Java-based tools that run inside Android.
